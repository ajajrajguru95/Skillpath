# Skillpath

Landing page for a fictional learning platform, built in Framer. The courses
section is a React code component that renders live data from a deliberately
unreliable API.

- **Component:** [`framer/CoursesGrid.tsx`](framer/CoursesGrid.tsx)
- **Tests:** [`test/`](test)

```bash
npm ci
npm test        # vitest
npm run typecheck
```

More detail - architecture, the currency logic and the failure handling - is
added as the component lands.
